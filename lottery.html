Seeded Lottery Draw

Pick one winner from each group of 10 using a public "seed" (a starting number used by a computer to generate random results). Anyone with the same entry list and seed gets exactly the same winners, so the draw can be checked independently.

Steps to run a draw

  1. Paste the list of entries into Step 1. In the tracker's "Responses" tab, copy the “Response IDs” of this round's valid entries (sort by start date/time from earliest to latest) and paste them into the box in Step 1 below. Check the round number and group size. Note that list order will affect lottery draw results; only the same list in the same order will generate the same "pool fingerprint".
  2. Get the seed and paste it into Step 2. A public "seed" can be anything from external sources, such as California Powerball numbers www.calottery.com.
  3. Record the winners. The winners appear in Step 3. Click "Copy for Draw Log" and paste into the tracker. Then click "Copy draw record" and save a copy.
  4. Let anyone check. Anyone who pastes the same list and the same seed into this page, or runs the R code at the bottom, gets exactly the same winners.

How winner is picked randomly?

The public "seed" acts as a random code published by an outside organization, so nobody can choose it.

  • Unique mix. Four things are combined: the seed, the list's fingerprint, the round number, and the group number. They are fed into a digital "shuffler" called SHA-256, a standard also used in banking and security. The same input always gives the same result, but changing even one letter gives a completely different result, and no one can predict the result.
  • Count off. The SHA-256 transforms the unique mix into a very large number. Divide the number by 10 and keep only the remainder, which is a random number from 0 to 9. Add 1 to the number; that leaves us with a simple number from 1 to 10.
  • Pick. That number is the winner's place in the group. If it's 9, the 9th entry in that group wins.

Why this is random: The seed is based on public information; anyone can repeat it and get the same answer with the same list.

Seed+ List fingerprint+ Round+ Group →SHA-256 →Number from 1 to 10 →Winner
